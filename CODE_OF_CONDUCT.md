# Community guidelines

We welcome contributors of all backgrounds and experience levels. Be respectful, assume good intent and keep criticism specific to the work.

Harassment, threats, discriminatory language, sexualized content directed at participants, doxxing and repeated disruptive behavior are unacceptable. Do not publish another person's private information.

These expectations apply to this project's issues, pull requests, reviews and other project spaces. Maintainers may edit or remove harmful content, restrict participation or ban participants based on severity and repetition. Maintainers are expected to apply these rules consistently and explain moderation decisions where doing so does not expose private information.

Report conduct concerns privately through a maintainer's available GitHub profile contact. If no private channel is available, use GitHub's report-abuse tools rather than posting personal details in a public issue. Good-faith reports should be handled confidentially to the extent possible; retaliation is unacceptable.
